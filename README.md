# MATLAB for Chemical Engineering

A collection of MATLAB programs developed during Chemical Engineering coursework and laboratory exercises.

## Contents

1. **Basics** — MATLAB functions, arrays, control flow and elementary calculations
2. **Plotting and Visualization** — engineering plots and graphical analysis
3. **Linear Algebra** — Gaussian elimination and Gauss-Seidel iteration
4. **Root Finding and Iteration** — bisection and successive-substitution/fixed-point methods
5. **Interpolation** — Lagrange and Newton divided-difference interpolation
6. **Series and Approximation** — Taylor-series approximation and error analysis
7. **Chemical Engineering Applications** — terminal velocity and methane equation-of-state calculations
8. **Engineering Applications** — tank volume, financial calculation and singularity-function beam analysis
9. **Practice and Exercises** — additional coursework practice programs

## Numerical methods covered

- Bisection method
- Fixed-point / successive substitution
- Gaussian elimination
- Gauss-Seidel iteration
- Lagrange interpolation
- Newton divided-difference interpolation
- Taylor-series approximation

## Chemical Engineering applications

The repository includes calculations involving concentration as a function of time, terminal velocity with Reynolds-number-dependent drag, and methane specific volume using an equation of state.

## Note

These programs are preserved from coursework/laboratory work and organized by topic for easier reference.
